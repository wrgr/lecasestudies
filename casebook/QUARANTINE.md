# Quarantine list

Cases withheld from every build (print main volume, digital supplement, complete reference build, overview booklets, companion) and from the matrix / indexes. The case blocks remain in the chapter sources and are fully recoverable — delete the slug from `lib/quarantine.typ` to restore a case. Global numbering keeps its gaps; slugs are the stable IDs.

**Basis:** the 2026 LENS-alignment audit (seven per-Part scans; see `AUDIT.md`). A case was quarantined only when its core lesson is **not a capability problem** (fraud / finance / philanthropy / pure-mechanical failure) or when it is **redundant** with a stronger sibling that teaches the same lesson. Non-traditional evidence tiers were **not** grounds for quarantine. None of the 14 was in the printed 48-case main volume, so the printed cut is unchanged; the corpus is 205 → **191**.
